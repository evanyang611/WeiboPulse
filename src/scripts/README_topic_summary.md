# 微博话题总结脚本使用说明

`topic_summary.py` 是一个用于从数据库中选取过去指定时间内特定分组的微博内容，并使用通义千问大模型生成话题总结的脚本。

## 功能介绍

1. 从数据库中查询指定分组在过去几小时内的微博内容
2. 根据用户提供的关心话题列表，调用通义千问大模型进行内容分析
3. 生成结构化的话题总结，突出与用户关心话题相关的信息
4. 支持将结果输出到控制台或保存到文件

## 使用方法

### 基本用法

```bash
python topic_summary.py --group 分组名称 --topics 话题1,话题2,话题3
```

### 参数说明

- `--group`：**必填**，指定要查询的微博账号分组名称
- `--topics`：**必填**，关心的话题列表，多个话题用逗号分隔
- `--hours`：可选，查询过去几小时的微博，默认为6小时
- `--output`：可选，指定输出文件路径，如果不提供则输出到控制台

### 示例

1. 查询"娱乐"分组过去6小时的微博，关心"新电影上映"和"明星活动"话题：

```bash
python topic_summary.py --group 娱乐 --topics "新电影上映,明星活动"
```

2. 查询"科技"分组过去12小时的微博，关心"AI发展"话题，并将结果保存到文件：

```bash
python topic_summary.py --group 科技 --topics "AI发展" --hours 12 --output summary.txt
```

## 输出格式

脚本输出的话题总结格式如下：

```
以下为今日（日期）的热点资讯：
在「话题1」话题中，有以下新资讯：
- 资讯1
- 资讯2
...

在「话题2」话题中，有以下新资讯：
- 资讯1
- 资讯2
...
```

## 注意事项

1. 确保已正确配置通义千问大模型的API密钥（在.env文件中设置ALIYUN_API_KEY）
2. 脚本需要在项目根目录下运行，或者确保Python路径正确设置
3. 如果指定的分组不存在或者该分组在指定时间范围内没有微博内容，脚本将给出相应提示
4. 大模型生成的内容可能会根据输入的微博内容和关心话题有所不同

## 定时执行

可以结合crontab等工具定时执行该脚本，例如每6小时执行一次：

```bash
0 */6 * * * cd /path/to/project && python src/scripts/topic_summary.py --group 娱乐 --topics "新电影上映,明星活动" --output /path/to/summaries/summary_$(date +\%Y\%m\%d_\%H\%M).txt
```

## 故障排除

如果遇到问题，请检查：

1. 日志文件（位于logs目录）中的详细错误信息
2. 确认数据库连接正常
3. 验证通义千问API密钥是否有效
4. 检查指定的分组是否存在，以及是否包含有效的账号
